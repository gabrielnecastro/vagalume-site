# Decisions and fixes

[← Specification index](README.md) · [Screen vs. API divergences](divergences.md)

What the product owner decided about each divergence and finding, and what was fixed on each day. The divergences and findings themselves are in [`divergences.md`](divergences.md).

On 2026-10-17 the product owner decided that only the behavior described in the QA guide (`/pages/qa-docs.html`) is intentional. Anything else that departs from this specification is a defect and must be fixed so the app matches the guide.
